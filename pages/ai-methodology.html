The Software
AI Methodology

Real AI Methods Used in the Software System

The system uses real machine-learning components to support quality review prioritization and documentation. The methods do not provide diagnosis, medication advice, treatment recommendations, or clinical action instructions.

Supervised ML

Risk Prediction

The selected model is Logistic Regression trained on patient_features_ai.csv. The model predicts probability for hospital_expire_flag on held-out data using a preprocessing pipeline.

Explainable AI

Feature Importance

The system uses saved model feature importance to show which transformed features contribute most strongly to the model signal for review support.

Similar cases

KNN Retrieval

Nearest-neighbor retrieval finds similar processed ICU cases using available numeric features. Similar cases are context only, not treatment guidance.

Clustering

KMeans Context

KMeans groups cases into clusters to provide broad cohort context for a reviewed case.

Anomaly detection

IsolationForest

IsolationForest estimates whether a case looks unusual compared with the processed academic dataset.

Uncertainty

Probability, Entropy, Threshold Distance, Data Quality

Uncertainty combines predicted probability, entropy, distance from Low/Medium/High thresholds, missing important features, and data quality.

Generative AI Boundary

Optional Live Generative AI

Live generative AI is optional and only runs when LLM_API_KEY is configured. Without that key, the system may show structured local summaries derived from the model outputs, but those are not presented as live generative AI.

No fake offline generative AI: Any offline summary must be understood as deterministic review text assembled from local model outputs and workflow context.
Safe Scope

What the AI Does Not Do

  • It does not diagnose patients.
  • It does not recommend treatment, medication, or emergency action.
  • It does not replace clinical staff or hospital policy.
  • It supports quality review prioritization, documentation, and auditability only.
