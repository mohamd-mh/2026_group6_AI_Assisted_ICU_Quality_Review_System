Simple Start

Run the Software

After downloading Software_System.zip, extract it first. Open a terminal inside the extracted Software_System folder and first try to run the application directly: 

python app.py

Then open http://127.0.0.1:5000 in the browser.

Git Bash Backup

If Dependencies Are Missing

If python app.py does not work in Git Bash because dependencies are missing, create a virtual environment and install the required packages: 

python -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
python app.py
PowerShell Backup

If Dependencies Are Missing

If python app.py does not work in PowerShell because dependencies are missing, create a virtual environment and install the required packages: 

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
PowerShell Fallback

If Activation Is Blocked

If PowerShell blocks the virtual-environment activation command, run the following command in the same terminal session: 

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Then activate the virtual environment again and run python app.py.

Local Store

Workflow Storage

The software creates a local SQLite workflow store at runtime for review items, manual cases, notes, prepared summaries, and audit events. The packaged zip excludes the existing runtime database so the submitted product starts clean.

Safety Scope

Quality-review support only

The software supports review prioritization and documentation. It does not diagnose patients, recommend treatment, prescribe medication, or replace qualified clinical staff.
