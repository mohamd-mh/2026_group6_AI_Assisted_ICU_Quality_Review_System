The Software
Workbench Overview

Product and Target User

The product is an AI-Assisted ICU Quality Review Workbench for an ICU Quality & Patient Safety Coordinator. It prioritizes, explains, and documents de-identified ICU case reviews using processed MIMIC-III data and transparent workflow records.

Main Capabilities

What the User Can Do

  • Open the quality review queue.
  • Add a new case for review.
  • View the processed ICU case library.
  • Run AI-supported review analysis.
  • View risk level, probability, and confidence.
  • Review explanation signals, similar cases, anomaly context, and uncertainty.
  • Prepare a Review Ticket and Prepared Review Summary.
  • Set status and priority.
  • Add coordinator notes.
  • Archive workflow records.
  • View audit history for traceability.
Problem

ICU review work is fragmented

Case prioritization, model context, review notes, follow-up status, and audit evidence can become disconnected.

Solution

One review workflow

The workbench gathers AI review support, review tickets, handoff summaries, and workflow documentation into one local information system.

Boundary

Quality review only

The prototype supports prioritization and documentation. It does not provide diagnosis, treatment, or emergency guidance.
