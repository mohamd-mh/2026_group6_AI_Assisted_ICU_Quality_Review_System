Dataset & Preprocessing

Processed Academic ICU Dataset

The runnable system uses a processed academic ICU feature dataset with 1000 ICU stays. Raw MIMIC files are not included in the final submission package.

Data Provenance

Source of patient_features_ai.csv

patient_features_ai.csv is a processed feature table derived from the full MIMIC-III v1.4 dataset provided by the course via a shared Google Drive folder (not a separate or unofficial data source). Source tables: PATIENTS.csv, ADMISSIONS.csv, ICUSTAYS.csv, CHARTEVENTS.csv (~33GB), LABEVENTS.csv, D_ITEMS.csv, D_LABITEMS.csv. Raw files are not included in this submission package due to size; the processed feature table is included instead. The original extraction script is not included in this submission.

Input Features

Model Inputs

The input schema uses demographic context, admission context, vital signs, and laboratory values:

gender, age, admission_type, heart_rate_avg, heart_rate_max, systolic_bp_avg, respiratory_rate_avg, temperature_avg, spo2_avg, creatinine_max, glucose_max, wbc_max, hemoglobin_min.

Leakage Control

Excluded Columns

The following columns are excluded from model input to prevent leakage and avoid using identifiers as predictors:

subject_id, hadm_id, icustay_id, hospital_expire_flag.

Important: hospital_expire_flag is used only as the supervised training/evaluation label and never as a prediction input.
Missing Values

Imputation and Feature Availability

The training pipeline uses median imputation for numeric values, standard scaling for numeric features, most-frequent imputation for categorical values, and one-hot encoding for categorical features.
