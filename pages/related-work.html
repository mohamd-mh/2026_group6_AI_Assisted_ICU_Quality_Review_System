Project-Related Literature

These five sources support the project framing: agent-inspired modular decomposition, plan-first AI-assisted development, ICU benchmark/prediction task design, MIMIC preprocessing practice, and the clinical scoring literature behind the SIRS baseline and the weighted clinical assessor. They are used as software engineering and methodological influences, not as clinical validation or runtime medical algorithms.

Paper 1

AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation

Main contribution: AutoGen presents multi-agent conversation as a programming abstraction, including conversable agents, role separation, tool and code execution, and flexible human-in-the-loop workflows.

Contribution to our project: This inspired the agent-like modular decomposition of the workbench into specialized components for prediction, screening, similar-case retrieval, anomaly detection, uncertainty, explanation, recommendation, and review-support summary. The project does not implement a full autonomous AutoGen system.

Paper 2

Planning-Driven Programming: A Large Language Model Workflow for Programming

Main contribution: Planning-driven programming separates reasoning from implementation: plan first, verify the plan, then code and debug using plan verification before code generation.

Contribution to our project: This inspired the development workflow with AI coding tools and the software's staged AI workflow trace: validate inputs, run prediction, screen, explain, recommend, summarize, and verify through smoke tests. LPW is not used or described as a runtime medical algorithm.

Download Paper

Paper 3

Harutyunyan et al. (2019) — Multitask Learning and Benchmarking with Clinical Time Series Data (MIMIC-III Benchmarks)

Main contribution: Harutyunyan et al. define a set of standard benchmark prediction tasks over MIMIC-III ICU time series (including in-hospital mortality) and a reproducible pipeline for building comparable ICU prediction datasets and models.

Contribution to our project: This informed how we scoped and framed patient_features_ai.csv as a processed, benchmark-style ICU prediction task, and grounded our choice of hospital mortality as the supervised label against established ICU outcome-prediction practice.

Paper 4

MIMIC-Extract / MIMIC Data Preprocessing Frameworks

Main contribution: MIMIC-Extract and related preprocessing frameworks describe reproducible pipelines for cleaning, aggregating, and imputing raw MIMIC chart and lab events into structured, model-ready feature tables.

Contribution to our project: This shaped our own preprocessing approach for deriving patient_features_ai.csv from raw MIMIC-III tables: aggregating vitals and labs per ICU stay, handling missing values with median/most-frequent imputation, and excluding identifier columns from model input.

Paper 5

SIRS (Bone et al., 1992) / APACHE II / SOFA and the Clinical AI Workflow Literature

Main contribution: Bone et al. (1992) define the Systemic Inflammatory Response Syndrome (SIRS) criteria used as a cited clinical baseline; APACHE II and SOFA are established severity-of-illness scoring systems that combine multiple weighted clinical signals into a single risk assessment.

Contribution to our project: SIRS supplies the cited 4-criterion baseline pipeline (replacing an earlier set of 10 ad-hoc, uncited rules), and the APACHE II/SOFA style of combining weighted clinical signals inspired the Weighted Clinical Assessor stage of the modular workflow, using uncalibrated engineering-judgment weights rather than a validated clinical scoring model.
